NetGuard · buildy bez Pro

Firewall Androida skompilowany od źródła — wszystkie funkcje Pro odblokowane, bez roota.

Gotowe

NetGuard to open-source'owy firewall dla Androida (licencja GPLv3) — blokuje internet dla wybranych aplikacji bez roota, przez lokalny tunel VPN.

Wersje z Play Store mają funkcje Pro za opłatą. Tu kompilujemy wersję debug od źródła — a w kodzie NetGuarda jest wbudowany mechanizm: jeśli aplikacja jest debuggable, funkcje Pro są traktowane jako zakupione. Dlatego ten build ma wszystko odblokowane, bez żadnych modyfikacji kodu i bez kluczy.

  • ✅ Bez roota — działa na zwykłym Androidzie
  • ✅ 32-bit i 64-bit — wybierz pod swój procesor
  • ✅ Kompilacja od źródła — pełna kontrola, powtarzalna
  • ✅ Konfiguracje urządzeń — wypychaj reguły na urządzenia przez ADB

Jak wgrać konfigurację

  1. Pobierz plik .json konfiguracji (powyżej).
  2. Podłącz urządzenie z włączonym debugowaniem USB.
  3. Uruchom: python apply_config.py <plik.json>
  4. Skrypt zatrzyma NetGuarda, wgra bazę reguł + ustawienia i go uruchomi.

Wymaga builda debug (ten z tej strony) — tylko on pozwala na run-as.
